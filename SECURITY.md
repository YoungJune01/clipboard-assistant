# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the default branch. This is
an early-stage project and does not currently maintain multiple supported
release lines.

## Reporting a Vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/YoungJune01/clipboard-assistant/security/advisories/new

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Do not include real clipboard contents, WebDAV
credentials, or other personal data in the report.

You should receive an acknowledgement within seven days. Confirmed issues will
be investigated and fixed before public disclosure whenever practical.
